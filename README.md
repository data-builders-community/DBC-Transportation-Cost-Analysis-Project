# Transportation Cost Analysis Project

The **Transportation Cost Analysis Project** is a collaborative data analytics initiative designed to help aspiring data analysts gain practical experience by collaborating with others and working on a real-world project from start to finish.

Rather than downloading an existing dataset, participants collect transportation fare data from their own cities, build interactive dashboards, and generate meaningful insights that can support better decision-making.

Once participants complete their individual projects, the datasets are combined into a larger collaborative dataset, allowing us to explore transportation patterns across multiple cities and uncover insights that wouldn't be possible from a single city alone.


## Project Overview

The project is divided into two phases:

### Phase 1: Individual City Analysis

Each participant independently collects transportation fare data from their own city using a standardized Excel template. They will clean, analyze, and visualize the data by building an interactive dashboard and preparing a short report based on their findings.

This phase gives every participant a complete end-to-end data analytics project that demonstrates skills in:

- Data collection
- Data cleaning and preparation
- Data analysis
- Data visualization
- Dashboard design
- Data storytelling and reporting

### Phase 2: Collaborative Analysis

Once participants have completed their individual projects, the datasets from each city will be combined into a larger dataset for a comparative analysis.

This collaborative dataset will allow participants to explore transportation patterns across multiple cities and generate insights that would not be possible from a single city's data alone.



## Why This Project?

Many data analytics portfolio projects rely on publicly available datasets from websites such as Kaggle or other online sources. While these datasets are excellent for learning technical skills, they don't provide experience in collecting, validating, and managing real-world data.

This project takes a different approach.

Instead of downloading an existing dataset, participants work together to build an original transportation fare dataset by collecting real data from their own cities. This provides practical experience with the complete data analytics workflow—from data collection to communicating actionable insights.

The project also emphasizes collaboration. Participants work independently on their own city analysis while contributing to a larger community project. Once the individual projects are complete, the datasets are combined into a collaborative dataset that enables comparative analysis across multiple cities.

Another unique aspect of this project is that the dataset can continue to grow over time. As transportation fares change, additional rounds of data collection can be carried out, allowing participants to analyze trends and build an increasingly valuable real-world dataset.


## Project Objectives

The Transportation Cost Analysis Project aims to:

- Enable participants to gain practical experience by collaborating with others on a real-world data analytics project.

- Build an original transportation fare dataset through community-driven data collection rather than relying on publicly available datasets.

- Develop practical skills in data collection, data cleaning, data analysis, data visualization, and dashboard design.

- Strengthen participants' ability to communicate data-driven insights through reports and presentations.

- Encourage collaboration, knowledge sharing, and constructive feedback among aspiring data analysts.

- Produce meaningful insights that can help individuals, researchers, and policymakers better understand transportation accessibility and commuting costs.

- Create a collaborative dataset that supports comparative analysis across multiple cities and can continue to grow through future rounds of data collection.

## Project Workflow

Participants will complete the project by following these steps:

1. **Choose a Destination Category**
   - Select a destination category that is relevant to your city, such as universities, major markets, business districts, or government hospitals.

2. **Plan Your Data Collection**
   - Identify the destinations you want to analyze.
   - Select residential areas using major bus stops or junctions as reference points.

3. **Collect Transportation Fare Data**
   - Use the project's Excel template to record transportation fares and other required information.
   - Verify fare information with drivers or regular commuters to ensure accuracy.

4. **Prepare and Clean the Data**
   - Review the collected data for completeness and consistency.
   - Organize the dataset so it is ready for analysis.

5. **Analyze the Data**
   - Explore the dataset to identify trends, patterns, and opportunities.
   - Answer relevant business questions based on your chosen destination category.

6. **Build an Interactive Dashboard**
   - Create visualizations that effectively communicate your findings.
   - Highlight key insights and performance indicators.

7. **Prepare Your Report**
   - Summarize your findings.
   - Present actionable recommendations supported by the data.

8. **Submit Your Project**
   - Upload your completed dataset and project files to the GitHub repository.

9. **Collaborative Analysis**
   - Once individual projects are completed, the datasets will be combined into a larger dataset for comparative analysis across multiple cities.
