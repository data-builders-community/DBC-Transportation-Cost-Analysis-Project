# Participant Data

This folder is for completed datasets submitted by participants in the Transportation Cost Analysis Project.

Participants should upload their completed datasets here after finishing their data collection.

## Before Submitting

Please make sure that:

- You have completed your planned data collection.
- Your dataset follows the project template.
- Each residential location or starting point has one selected common/practical route.
- Multi-stage journeys have been recorded stop-by-stop.
- Transportation fares have been checked for accuracy.
- Required fields are completed.
- Your dataset has been reviewed for missing or inconsistent information.

## File Naming

Please name your file using the following format:

`City_Name_Transportation_Data.xlsx`

### Example

`Port_Harcourt_Transportation_Data.xlsx`

Using a consistent naming format makes it easier to identify datasets from different cities.

## Submission

Upload your completed Excel dataset to this folder when your data collection is complete.

If you are unsure whether your dataset is ready for submission, ask in the project WhatsApp group before uploading it.
