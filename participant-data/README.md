# Participant Data

This folder contains completed project submissions from participants.

## Submitting Your Project

When you have completed your project, create a folder inside this directory using the following naming format:

`[Participant-Name]-[City]-[State]`

### Example

`Barbara-Mangiri-Port-Harcourt-Rivers`

Your folder should contain the materials for your completed project, including:

- Your transportation dataset
- Your project report
- Your dashboard or dashboard link
- Any other relevant files or information related to your analysis

Please keep all files related to your project inside your submission folder.
